# CK-Configuration

[![Licence](https://img.shields.io/github/license/signature-opensource/CK-Configuration.svg)](LICENSE)

This repository contains extensions and helpers to manipulate .NET configuration sections and to build configured objects from them.

| Package | Description | Latest stable |
|---------|-------------|---------------|
| [CK.Configuration](CK.Configuration/README.md) | Mutable and immutable configuration sections, plugin assemblies and typed configuration builder. | [![nuget](https://img.shields.io/nuget/v/CK.Configuration.svg?label=CK.Configuration)](https://www.nuget.org/packages/CK.Configuration/) |
